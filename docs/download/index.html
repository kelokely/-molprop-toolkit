Recommended: source checkout + conda

git clone https://github.com/kelokely/-molprop-toolkit.git molprop-toolkit
cd molprop-toolkit
conda env create -f environment.yml
conda activate molprop-toolkit
pip install -e ".[dev,parquet]"

When this is the right choice

  • You want RDKit-backed calculator features.
  • You want editable installs and the full CLI surface.
  • You plan to use reports, picklists, similarity, series, or retro from the same environment.
