Matched molecular pairs

Use RDKit-based fragmentation to build matched-pair tables and transform summaries from a MolScope-compatible campaign table. This is where repeated directional changes become visible instead of being hidden inside one-off analog pairs.

Command: molscope mmp.

Typical usage

molscope mmp campaign_integrated.csv -o campaign_mmp \
  --priority-metric Measured_pIC50 --metrics Measured_pIC50,Lead_LLE,CNS_MPO

What you get

A bundle with pair_table.csv, transform_summary.csv, summary.json, summary.md, and metadata describing the fragmentation settings used to generate the pairs.

Dependency note

Matched-pair analysis requires RDKit. Install RDKit through conda-forge before running this workflow. 

conda install -c conda-forge rdkit
