Decision picklists

Generates operational decision picklists from a results CSV using filters/sorts. Outputs one CSV per picklist and can optionally produce an HTML index and per-picklist pages. Built-in picklists provide sensible defaults, and you can supply a JSON/YAML config to define project-specific rules.

Command: molscope picklists.

List built-in picklists

molscope picklists results.csv --list-builtins

Run picklists (HTML + CSV)

molscope picklists results.csv --html

Stage-aware defaults

molscope picklists results.csv --stage hit-expansion --html
molscope picklists retrosynthesis/demo/retro_enriched.csv --stage lead-optimization --html

When you pass --stage without explicit --picklists, MolScope chooses a stage-appropriate subset of built-in picklists automatically. The current presets are hit-expansion, lead-optimization, backup-series, and liability-de-risking.

The current decision queues are built to feel more operational than the older export-style picklists: make_next, test_next, de_risk_next, hold, and backup_series.

Decision-ready outputs

Picklist outputs now carry explicit decision fields such as Decision_Queue, Decision_Rationale, Decision_Next_Action, Decision_Confidence, and Decision_Evidence_Summary. They now also include Decision_Hypothesis, Decision_Minimal_Test_Set, and Decision_Minimal_Analog_Set so the exported CSV and HTML pages suggest the smallest next experiment or chemistry move instead of stopping at ranking.

Measured support Heuristic support Campaign context

Decision_Confidence should be interpreted as an evidence-quality label, not a promise. Use the Uncertainty page when you want to know why one queue is ready for action and another is only a test prompt. 

molscope picklists campaign_integrated.csv --stage lead-optimization --html

Custom picklists via config

Start from the example config:

cp examples/picklists.example.json my_picklists.json

molscope picklists results.csv --config my_picklists.json --html

Embed structure images (optional)

# generate structure assets
molscope sketch results.csv --outdir sketches_compare --compare --html

# build picklists with embedded structure thumbnails
molscope picklists results.csv --html --sketch-dir sketches_compare --structure-views calc --structure-formats svg
