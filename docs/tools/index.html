Tooling

Tools organized around lab jobs

Each page below documents a single CLI command with common options and examples. For the authoritative, always-up-to-date help, run <command> --help. The pages are grouped by workflow so it is easier to find the job you need than to scan raw command names.

For everyday use, start with the unified workflow commands like molscope prep, molscope calc, molscope analyze, and molscope report. For campaign memory and decision support, the newer workflows are molscope integrate, molscope compare, molscope learnings, molscope dashboard, molscope sar, molscope mmp, molscope search, and molscope portal.

Core workflow

Extended calculator

Recommended starting point for most projects, surfaced publicly as molscope calc with the default extended profile.

Analyzer

Stable Calculated Heuristic

List categories, inspect a focused liability or opportunity area, and export category subsets through molscope analyze.

Report builder

Turn a results table into a shareable Markdown and HTML report bundle with stage-aware framing and experiment prompts through molscope report.

Picklists

Stable Measured Campaign

Create operational decision lists, hypothesis prompts, and minimal next-step test plans through molscope picklists.

Campaign memory and comparison

Assay integration

Preview Measured Campaign

Join measured potency or ADME data back into a MolScope table, stamp provenance, and optionally recompute lead metrics.

Campaign compare

Preview Measured Campaign

Compare two runs, rounds, or lead sets with overlap summaries, endpoint shifts, and group-level deltas.

Campaign learnings

Experimental Campaign Measured

Turn compare, SAR, MMP, and decision outputs into reusable project lessons and next-step cues.

Campaign dashboard

Experimental Campaign

Accumulate learnings bundles across rounds into a persistent dashboard with snapshot history, recurring lessons, and active campaign memory.

SAR bundle

Preview Campaign Measured

Summarize series by scaffold or series ID, rank top compounds, and export a scaffold-centric review bundle.

Matched molecular pairs

Preview Campaign Measured

Extract matched pairs and transform summaries so teams can see repeated directional changes instead of isolated rows.

Campaign search

Preview Calculated Utility

Search results tables by exact SMILES, SMARTS substructure, or motif panel without leaving the workflow.

Campaign portal

Preview Campaign Measured

Assemble report, compare, learnings, dashboard, SAR, MMP, picklist, and retro bundles into one linked HTML workspace.

Tip

A practical second-level loop is molscope integrate → molscope compare → molscope learnings → molscope dashboard → molscope sar / molscope mmp → molscope report / molscope picklists → molscope portal.

Why learnings matter

Learnings is the memory layer between raw comparison and action. It turns round-over-round shifts and transform signals into reusable lessons teams can carry into the next design review.

Why dashboard matters

Dashboard is the persistent memory layer above individual learnings bundles: one registry that keeps round history, recurring lessons, and the latest action cues in the same place.

Calculator profiles and preparation

Baseline calculator

Stable Calculated Heuristic

A smaller medchem-focused table when you want a simpler starting profile without the extended families.

Prep workflow

Stable Representation Structure handling

Use molscope prep presets for triage, ambiguity audit, 3D-ready protomer handling, or externally prepared structures.

Prep outputs

The prep command writes a standardized table with Prep_*, Tautomer_*, Stereo_*, and Protomer_* audit fields.

Compatibility

The calculator profiles still exist for compatibility, but prep is now a separate first-class step instead of just a cluster of calculator flags.

Operational triage

Decision picklists

Stable Measured Campaign

Generate decision picklists (CSV and optional HTML) from filters and project-ready sorts.

Retrosynthesis

Preview Campaign Optional

Offline retrosynthesis wrapper using AiZynthFinder (summary CSV/JSON + HTML route browser).

Similarity

Stable Calculated

Fingerprint similarity search, pairwise matrices, diversity picking, and simple clustering.

Tip

For MolScope results tables, similarity defaults to the toolkit structure-of-record SMILES and will prefer Calc_Canonical_SMILES when present.

Featurization

Stable Calculated

Model-ready features: fingerprints + fragments + functional groups + DL exports.

Schema utility

Stable Utility

Validate that a results CSV matches the toolkit schema and required categories.

Tip

For large libraries, generate features from Canonical_SMILES (standardized parent) for stability, and keep any protomer/stereo enumeration as a separate dataset variant.

Note

Deep-learning exports include packed-bit fingerprints, aligned SMILES for token models, and concatenated graph tensors for GNN pipelines.
