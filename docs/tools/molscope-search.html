Campaign search

Search campaign tables by exact SMILES, SMARTS substructure, or a reusable motif panel. This command is designed for med-chem review tables rather than only standalone SMILES files, so the hits stay inside the MolScope workflow.

Command: molscope search.

Exact and SMARTS queries

molscope search campaign_integrated.csv -o quinoline_hits \
  --smarts "c1nc2ccccc2cc1"

molscope search campaign_integrated.csv -o exact_hits \
  --exact-smiles "CCOc1ccc(NC(=O)N2CCOCC2)cc1"

What you get

A compact bundle with search_results.csv, summary.json, summary.md, and motif hit tables when you search a reusable panel.

Motif panels

molscope search campaign_integrated.csv -o alert_panel \
  --motif-file motifs.tsv

Motif files can be simple tab- or comma-delimited name/SMARTS tables. This makes it easy to keep project-specific motif panels or counterscreen motifs outside the calculator itself.

Dependency note

Substructure and motif searching require RDKit. Use this command when you want exact or motif-driven retrieval; use molscope similarity when the task is nearest-neighbor search or diversity selection.
