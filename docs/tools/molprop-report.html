Report builder

Builds a shareable report bundle from a results CSV. The report includes category summaries and plots and writes both Markdown and HTML output into a timestamped directory under reports/.

Command: molscope report.

Typical usage

molscope report results.csv

What you get

A folder like reports/<stem>_report_YYYYMMDD_HHMMSS/ containing report.md, report.html, and a plots/ subfolder.

Stage-aware framing

molscope report results.csv --stage lead-optimization
molscope report retrosynthesis/demo/retro_enriched.csv --stage backup-series

Stage presets add a campaign-aware summary near the top of the report and highlight the columns most relevant to that decision context. The current presets are hit-expansion, lead-optimization, backup-series, and liability-de-risking.

Decision products

Reports now include a decision-products section that summarizes operational queues such as make_next, test_next, de_risk_next, hold, and backup_series. The section also separates measured priority evidence from calculated or heuristic signals so teams can see how much of the recommendation is grounded in real data, then adds experiment prompts describing the current hypothesis, the minimal next test set, and the narrowest analog set worth making before the next round.

Measured priority evidence Heuristic support Campaign context

Read these layers separately. The report is strongest when measured support, heuristic direction, and round context point the same way. See Uncertainty for how confidence should change when those layers disagree. 

molscope report campaign_integrated.csv --stage lead-optimization

Tip

If you want a clean, portable artifact for collaborators, send the entire report directory (or zip it). The HTML report is intended to be readable without a Python environment.
