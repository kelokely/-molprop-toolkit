Campaign learnings

Distill compare, SAR, MMP, and decision outputs into reusable project lessons so the campaign remembers what changed, what helped, what hurt, and what should be tested next.

Command: molscope learnings.

Typical usage

molscope learnings \
  --compare-dir compare/demo \
  --sar-dir sar/demo \
  --mmp-dir mmp/demo \
  --picklists-dir picklists/demo \
  -o learnings/demo

What you get

A learnings bundle with learning_cards.csv, summary.json, summary.md, and a browsable index.html that turns artifact outputs into project memory.

Why it matters

Compare tells you what changed. SAR and MMP tell you where the signal lives. Decision products tell you what should move next. molscope learnings turns those into reusable lessons that survive beyond one run or one slide deck.

Use it with dashboard and portal

molscope dashboard \
  --learnings-dir learnings/demo \
  -o dashboard/demo

molscope portal \
  --report-dir reports/demo \
  --picklists-dir picklists/demo \
  --compare-dir compare/demo \
  --learnings-dir learnings/demo \
  --dashboard-dir dashboard/demo \
  -o portal/demo

The learnings bundle becomes especially useful when folded into a persistent dashboard and then linked from the campaign portal, because that gives project teams a short path from raw evidence to remembered lessons.
