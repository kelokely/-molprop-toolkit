SAR bundle

Build a scaffold-centric SAR review bundle from a series-enriched MolScope table. The current workflow groups by Scaffold_ID by default, summarizes the series, and ranks top compounds so a team can review SAR with consistent metrics instead of a raw campaign sheet.

Command: molscope sar.

Typical usage

molscope sar campaign_integrated.csv -o campaign_sar \
  --group-column Scaffold_ID --priority-metric Measured_pIC50

What you get

A SAR bundle with series_summary.csv, top_compounds.csv, metric_summary.csv, summary.json, summary.md, and run metadata.

Choose the right metrics

molscope sar campaign_integrated.csv -o cns_sar \
  --metrics Measured_pIC50,Lead_LLE,CNS_MPO,Sol_ESOL_LogS \
  --priority-metric Lead_LLE

The first release is intentionally lightweight: it does not try to do full R-group decomposition yet. Instead, it gives a stable scaffold-centric summary that can feed report bundles and design discussions right away.
