Retrosynthesis

Offline retrosynthesis planning wrapper based on AiZynthFinder. This command delegates planning to AiZynthFinder’s aizynthcli and then post-processes the results into a summary CSV/JSON plus a lightweight HTML browsing site with optional route images.

Command: molscope retro.

Install dependencies

AiZynthFinder is intentionally an optional dependency. Install it when you want retrosynthesis:

# inside your conda env
pip install -e .

# install AiZynthFinder separately
pip install aizynthfinder[all]

Download models + stock and create a config

AiZynthFinder provides a helper that downloads public data and writes a usable config file.

download_public_data aizynth_data

# this creates aizynth_data/config.yml

Run retrosynthesis on a results CSV

molscope retro results.csv --config aizynth_data/config.yml --top-routes 5 --nproc 4 --rerank-policy balanced

# Write a retro-enriched campaign table for downstream reports/picklists
molscope retro results.csv --config aizynth_data/config.yml --rerank-policy stock-first --write-retro-table

# If your CSV uses non-standard columns
molscope retro results.csv --config aizynth_data/config.yml --smiles-col SMILES --id-col Compound_ID

Outputs a directory under retrosynthesis/ containing routes_summary.csv, routes_summary.json, summary.md, index.html, per-target pages, optional route PNGs, and optionally retro_enriched.csv for downstream campaign workflows.

Run retrosynthesis on a SMILES list

molprop-retro targets.smi --config aizynth_data/config.yml

The input can be a single-column SMILES file or a two-column name/SMILES file.

Reranking policies

MolScope now reranks route summaries so retrosynthesis can act as a practical prioritization signal, not just a raw route dump.

  • balanced: mix route score, solved status, stock coverage, and step burden.
  • score: stay closest to AiZynthFinder top scores.
  • stock-first: prefer compounds with higher precursor stock coverage.
  • shortest: prefer shorter routes when route counts are similar.

Notes

Retrosynthesis quality depends heavily on the chosen policy model and stock definition. The public download is a good starting point, but real project use typically requires a curated purchasables stock and tuned settings. MolScope Toolkit treats retrosynthesis outputs as a prioritization signal (route score, step count, precursors in stock, and rerank policy), not as a guarantee of synthetic feasibility.
