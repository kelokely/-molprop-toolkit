Assay integration

Merge measured assay endpoints back into a MolScope-compatible results table, stamp provenance for imported fields, and optionally normalize potency into Measured_pIC50 so downstream lead metrics can be recalculated from measured rather than heuristic values.

Command: molscope integrate.

Typical usage

molscope integrate results.parquet assays.csv -o campaign.parquet \
  --potency-column IC50_nM --potency-scale ic50_nm

What you get

A merged campaign table that stays compatible with molscope report and molscope picklists, plus a standard metadata sidecar describing inputs and imported fields.

Control imported columns

molscope integrate results.csv assays.csv -o campaign.csv \
  --left-id Compound_ID --right-id Compound_ID \
  --assay-columns IC50_nM,Solubility_uM,Caco2_AtoB \
  --prefix Measured

By default the command imports every assay column except the join key. Use --assay-columns when you want a smaller measured-data surface or cleaner naming.

Why it matters

molscope integrate is the bridge from heuristic triage to campaign memory. Once measured potency, solubility, permeability, or safety panel data live in the same table, compare, SAR, MMP, report, and picklist workflows can reason from project outcomes instead of only calculated signals.
