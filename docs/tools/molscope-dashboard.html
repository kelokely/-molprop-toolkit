Campaign dashboard

Build a persistent cross-round dashboard and knowledge registry from one or more learnings bundles so the campaign keeps a durable memory of what changed, what keeps repeating, and what still deserves action.

Command: molscope dashboard.

Typical usage

molscope dashboard \
  --learnings-dir learnings/round4 \
  -o dashboard/campaign_alpha

molscope dashboard \
  --learnings-dir learnings/round5 \
  -o dashboard/campaign_alpha

What you get

A persistent dashboard with snapshot_registry.csv, knowledge_registry.csv, active_learning_cards.csv, recurring_lessons.csv, summary.md, a browsable index.html, and copied learnings bundles under snapshots/.

Why it matters

Learnings captures what one round taught the team. Dashboard carries those lessons forward across rounds, with snapshot history, recurring lessons, and the active cards that should still shape the next design or assay cycle.

Use it with portal

molscope portal \
  --report-dir reports/round5 \
  --picklists-dir picklists/round5 \
  --learnings-dir learnings/round5 \
  --dashboard-dir dashboard/campaign_alpha \
  -o portal/round5

Pair the current-round portal with the persistent dashboard when you want one shareable workspace that shows both the latest evidence and the longer-term campaign memory behind it.
