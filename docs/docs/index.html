Recommended reading order: start with the quickstart, then the command summary, then the category guide when you want interpretation help for specific risk families. Add the methods and uncertainty pages once you need to decide how hard to lean on a given signal.

For a new user

Use the quickstart and command summary first. Those two pages cover install, the canonical workflow, and the expected shareable outputs.

For a returning project team

Use the category guide and feature-family reference when you need to understand what a signal means and how it should affect assay or design choices.

For scientific grounding

Use methods, representation policy, validation, and uncertainty when you want the site to show its work instead of only its workflow.

For job-based navigation

Use the use-cases page when you know the task you are trying to complete but do not yet know which commands or artifacts fit best.
