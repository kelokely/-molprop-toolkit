Data contract

How MolScope tables are organized

The table format is designed so analyzers, reports, picklists, and future integrations can all treat the results file as the canonical dataset.

Identifier rules

Compound_ID is the preferred identifier. If it is missing, most analyzers fall back to the first column, but projects should normalize to Compound_ID for the smoothest workflow.

Structure-of-record priority

When downstream tools need a SMILES column, they prefer Calc_Canonical_SMILES, then Calc_Base_SMILES, then Canonical_SMILES, and only then raw SMILES.
