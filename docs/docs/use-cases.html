Jobs

Start from the job, not the command list.

MolScope is easiest to learn when you route from the chemistry task you are trying to complete. These job paths keep the public surface small while still exposing deeper campaign-memory workflows.

Stable Heuristic triage Calculated descriptors

Triage a fresh library

Best when you have SMILES, no measured data yet, and need a med-chem-first table plus immediate next-step queues.

molscope prep if structure handling needs to be explicit. molscope calc to generate the canonical table. molscope analyze, molscope report, and molscope picklists to create review-ready outputs.

Start here for ranking, screening, and “what should we test first?” workflows.

Preview Measured data Campaign memory

Merge assay data into the campaign table

Best when potency, solubility, permeability, or safety panel data have arrived and the project needs one source of truth again.

molscope integrate to join assay endpoints and stamp provenance. molscope report --stage ... to shift the story from heuristic rank to measured campaign state. molscope picklists to produce measured-priority queues.

This is the bridge from pre-assay triage to project memory.

Preview Measured deltas Round comparison

Compare one round to the last round

Best when the project question is about movement: which series improved, which liabilities worsened, and where the campaign is drifting.

molscope compare to summarize dataset, endpoint, and scaffold shifts. molscope learnings to extract reusable lessons. molscope dashboard to persist those lessons across rounds.

Use this route when the unit of meaning is the campaign, not one table.

Preview Series context Measured metrics when present

Review a scaffold split or SAR branch

Best when multiple chemotypes or substitution branches are competing for attention and the team needs reusable SAR summaries.

molscope series for scaffold and cluster context. molscope sar for scaffold-centric bundle outputs. molscope mmp when matched-pair transforms are the clearest way to summarize change.

Use this route to turn rows into project learnings rather than ad hoc notebook conclusions.

Preview Cross-linked outputs Measured + heuristic mix

Build a collaborator-ready bundle

Best when you want the campaign story to survive outside the terminal and outside the local Python environment.

molscope report and molscope picklists --html for review-ready artifacts. molscope portal to assemble reports, picklists, compare, learnings, dashboard, SAR, MMP, and retro outputs into one workspace.

This is the most effective path for project meetings and collaborator handoff.

Stable Workflow utility Structure handling

Prepare structures for 3D-heavy work

Best when salts, tautomers, protonation, or stereochemistry will materially change 3D descriptors, clustering, or human interpretation.

molscope prep --preset 3d for representation-aware preparation. molscope calc with 3D output options when geometry-sensitive descriptors are needed. molscope sketch for portable structure review sheets.

Use the representation policy page to decide which form should be treated as the structure of record.
