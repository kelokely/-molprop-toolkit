Workflow

Canonical MolScope commands

The public command surface is intentionally small: one workflow, a few specialist commands, and compatibility aliases for older `molprop-*` entrypoints.

Docs hub Commands Categories Feature families Columns Use cases Methods Validation Representation Uncertainty

Core workflow

molscope calc library.smi -o results.parquet
molscope analyze results.parquet --list
molscope report results.parquet
molscope picklists results.parquet --html

Bundle those outputs

molscope portal --report-dir reports/demo \
  --picklists-dir picklists/demo \
  --compare-dir compare/demo \
  -o portal/demo

Calculator profiles

  • extended: recommended default profile for full med-chem and developability triage.
  • baseline: smaller med-chem-first profile for lighter runs and simpler tables.
