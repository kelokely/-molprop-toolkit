Credibility

What is tested today

MolScope is strongest today as a reproducible workflow, a transparent chemistry-table standard, and a set of review-ready outputs. Many scientific signals remain intentionally heuristic, and the docs label them that way.

Current validation posture: MolScope is release-gated as a working campaign workflow first. Formal calibration of heuristic endpoints is a separate and still-growing layer.
Layer What is validated now Main remaining risk
Workflow contract CLI entrypoints, schema handling, report/picklist generation, compare/portal/dashboard/learnings bundle creation, and Pages-published docs. Regression risk when the public command surface changes faster than acceptance coverage.
Deterministic table handling Schema compatibility, identifier handling, provenance columns, and campaign-table joins. Join quality still depends on the input IDs and structure-of-record policy chosen by the project.
Descriptor and rule families Stable calculation and documentation of their intended use as ranking/triage aids. Absolute interpretation can drift if users treat heuristics as validated predictions.
Campaign-derived workflows Unit and smoke coverage for compare, SAR, MMP, learnings, dashboard, and portal bundle structure. Sparse measured data or weak series context can still generate fragile lessons.

Release gates

A release should preserve the canonical quickstart path, stable schema loading, and the shareable artifact workflows users see on the public site.

Why this page matters

MolScope is meant to be clear about both capability and confidence. This page brings the release checks, evidence boundaries, and confidence labels together in one place.

What MolScope does not currently claim

No replacement for assays

Solubility, permeability, PK, safety, and developability outputs are supports for experiment planning. They are not substitutes for measured ADME, electrophysiology, or in vivo studies.

No universal calibration yet

The public site does not yet ship benchmark plots that show how every heuristic family tracks against external public datasets across chemistry space.

No black-box “AI score”

The campaign-memory and decision layers are table-driven and provenance-aware. Their value comes from transparent synthesis of evidence, not opaque prediction.

No certainty from sparse context

Round-to-round or transform-derived lessons are only strong when the campaign has enough analog support and measured follow-up to justify them.

Benchmark roadmap

Near term

Publish benchmark bundles for workflow, measured-data joins, compare summaries, and decision-product outputs. The first consolidated view now lives on the benchmarks page.

Later

Add campaign-level evaluation for compare, learnings, and decision-product usefulness using example round histories and accepted follow-up outcomes.
