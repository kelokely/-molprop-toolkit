MolScope Toolkit: from SMILES to practical medchem triage.

Created by Elokely Lab • University of Wyoming School of Pharmacy

MolScope Toolkit turns SMILES libraries into analysis-ready property tables, then helps teams summarize liabilities, build shareable reports, and prioritize compounds for the next round of chemistry or profiling.

MolScope is organized around one practical workflow: calculate a table, review the signals that matter, generate a report, and turn the results into concrete picklists.

One straightforward workflow

Most teams use the toolkit the same way: create a results table, inspect categories, package the findings, and turn them into experiment-ready lists.

1

Calculate

Start from SMILES and generate a wide medicinal chemistry results table.

molscope calc library.smi -o results.parquet
2

Analyze

Preview the categories and inspect the liabilities or strengths that matter to the project.

molscope analyze results.parquet --list
3

Report

Create a shareable bundle for medicinal chemistry, DMPK, and project review.

molscope report results.parquet
4

Prioritize

Export operational picklists for follow-up assays, synthesis planning, or series review.

molscope picklists results.parquet --html

The generated outputs do more than list columns. They show the current stage, the evidence behind a recommendation, the top operational queues, and the smallest next experiments worth running.

Why this matters

Designed to survive a real project meeting

The intended audience is not just the CLI user. Reports, picklists, and the campaign portal are built so medicinal chemists, DMPK scientists, and project leads can all see the same recommendation trail.

Measured signals are separated from heuristic and campaign-derived evidence instead of being blended into one rank. Queues are named by job: what to make next, what to test next, what to de-risk next, and what to hold. Minimal assay and analog sets are surfaced so the output suggests the next discriminating experiment, not just the next score. Round-review summaries highlight positive shifts, negative shifts, and low-coverage endpoints before a team overreads sparse campaign movement.

Install

For the calculator features you’ll need RDKit. The most reliable public install path is conda‑forge (or Docker). If you already have a compatible results CSV from another pipeline, you can run analyzers without RDKit.

Recommended: conda (RDKit‑friendly)

git clone https://github.com/kelokely/-molprop-toolkit.git molprop-toolkit
cd molprop-toolkit

conda env create -f environment.yml
conda activate molprop-toolkit

# editable install with console scripts + Parquet support
pip install -e ".[dev,parquet]"

Recommended first run

# calculator -> results table (CSV or Parquet)
molscope calc examples/example.smi -o results.parquet

# summary report (md + html)
molscope report results.parquet

# picklists
molscope picklists results.parquet --html

Preclinical profiling

MolScope Toolkit already covers many of the signals teams review before expensive experimental follow-up. The toolkit organizes those outputs into two practical tracks so you can move from structure-based heuristics to experiment planning without rebuilding the dataset.

Property-based heuristics Assay data can be merged back in Best used comparatively within a campaign
Important: these modules are supports for experiment planning and project communication. They do not replace ADME/PK assays, electrophysiology, or in vivo studies.

In vitro-relevant modules

Use these modules to rank compounds for assay readiness, early ADME/Tox counterscreens, and mechanism-focused liability review.

  • Solubility and permeability heuristics for dissolution, absorption, and efflux triage
  • Metabolism, CYP, and hERG analyzers for soft spots, inhibition burden, and safety flags
  • Toxicity and med-chem alert narratives for interpreting rule-based liabilities

In vivo-relevant modules

Use these modules to summarize likely exposure headwinds and decide which series deserve fuller PK and efficacy work.

  • PK-oriented outputs covering protein binding, distribution, clearance risk, and oral exposure class
  • Report generation for sharing preclinical package snapshots with project teams
  • Picklists and series analytics for prioritizing compounds and scaffolds before in vivo studies
